# PORTOROBOTIC: Portofolio Hardware, Firmware, dan PCB

## Deskripsi

Website portofolio hardware milik Afra Fadhma Dinata. Isinya proyek desain PCB, firmware ESP32 dan STM32, sistem IoT, pengalaman organisasi, keahlian, dan sertifikat. Situs dibuat dengan HTML, CSS, dan JavaScript murni tanpa framework. Animasinya meliputi loading drone, parallax, dan robot AFD-bot di setiap bagian.

Demo: [robotic.aefera.me](https://robotic.aefera.me/)

## Menjalankan

Buka `index.html` di browser, atau jalankan server lokal dari folder proyek:

```bash
python -m http.server 8000
```

Lalu buka `http://localhost:8000`. Semua teks dan path gambar diatur di `js/data.js`.
